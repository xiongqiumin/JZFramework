=== StepEditDialog 转换报告 ===

- 类替换(11 类):
    QCheckBox -> CheckBox              x1
    QComboBox -> ComboBox              x1
    QDialog -> Dialog                  x1
    QDoubleSpinBox -> SpinBox          x1
    QGridLayout -> VBoxLayout          x2
    QGroupBox -> GroupBox              x1
    QLabel -> Label                    x10
    QLineEdit -> LineEdit              x7
    QPushButton -> PushButton          x2
    QSpinBox -> SpinBox                x2
    QWidget -> Widget                  x2

- 被忽略的属性(8 种):
    layout.leftMargin              x3
    layout.topMargin               x3
    layout.rightMargin             x3
    layout.bottomMargin            x3
    sizePolicy                     x3
    windowTitle(->title)           x1
    decimals                       x1
    singleStep                     x1

- 被忽略的元素(1 种):
    spacer                         x3

- 语义损失 / 需要人工看的点:
    * QGridLayout -> VBoxLayout: 栅格位置 / 标签列丢, 按声明顺序竖排
    * QDoubleSpinBox -> SpinBox(整数): 小数会被截断, 用到的地方要改逻辑
