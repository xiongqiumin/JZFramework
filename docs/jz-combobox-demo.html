2. 同一组件, 不同 style (宿主类 + part 覆盖, popup 也各自定义)

big-arrow: popup 超过 max-height 后可滚动 (overflow 由 ::part(popup) 定义)。

箭头在左 = ::part(arrow) { order: -1 }; 展开时箭头变色旋转。

4. dark 主题 (仅覆盖令牌, 组件规则零改动)

5. 事件契约 (CustomEvent: change)

验证清单: 1) part(display/arrow/popup/option) 全部可被外部 CSS 定义; 2) part + 伪类 (:hover/:active); 3) part 多 token (option selected); 4) 宿主类变体 (primary/big-arrow/arrow-left); 5) 令牌穿透 Shadow DOM (dark); 6) popup 为独立浮层 (fixed, 不被父裁剪) + 点外关闭 + Escape + 可滚动; 7) change CustomEvent; 8) 箭头换边 = CSS order; 9) .open 状态类 -> 箭头旋转。 命名注: 浏览器要求自定义标签含连字符 (jz-combobox); JZFramework 引擎无此限制, 标签即类名 (JZComboBox)。part 契约两边一致。
