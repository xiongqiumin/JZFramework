弹窗 dialog

基于原生 <dialog> —— 焦点陷阱、Esc、顶层渲染都由浏览器负责， 我们只加外观。JzUI.dialog() 返回 Promise<value>， JzUI.confirm() 返回 Promise<boolean>。

手机端宽度 calc(100vw - 24px)、按钮等分整行且 ≥44px； 点遮罩 / Esc 关闭；closable:false 可禁止右上角关闭。

最简用法

JzUI.confirm('删除后不可恢复，继续？', { danger: true })
  .then(ok => JzUI.toast(ok ? '已删除' : '已取消', ok ? 'ok' : ''));

JzUI.dialog({ title: '详情', size: 'lg', body: '<p>任意 HTML</p>' });

提示 toast

JzUI.toast(text, kind)，kind = ok / fail / warn； 同时最多 3 条，3s 自动消失，aria-live="polite"。
